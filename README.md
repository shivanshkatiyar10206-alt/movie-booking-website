# iMovies Static Website

A responsive, front-end-only cinema booking demo built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in your browser. No installation, server, database or API keys are required.

## Features
- Responsive cinema landing page
- Movie cards with genre filters
- Movie selection and showtime/date selectors
- Interactive seat map with available, selected and occupied seats
- Demo booking confirmation and price calculation

## Important
This is a static front-end demo. Authentication, real-time seat synchronization, payment processing, and database storage are not implemented. Movie posters are loaded from external image URLs, so an internet connection is needed for those images.
